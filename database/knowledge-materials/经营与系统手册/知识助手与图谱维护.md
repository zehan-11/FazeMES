# 知识助手与图谱维护

适用范围　知识库管理

## 知识库怎样添加、修改资料并更新知识图谱？

在 RAG 知识库选择可维护的库，上传文档并发布。更新同一份文件时使用行内更新文件，保存新版草稿后重新发布。等待图谱同步完成，打开知识图谱重新加载，再按实体名查来源版本。

## 怎么选文档、图谱或混合检索？

查操作步骤先用文档检索，查实体与关系可用图谱检索，一起核对原文和关联用混合检索。先查看来源，再结合证据提问。

## Dify 和业务 Agent 各适合问什么？

Dify 教学手册入口查询其组件绑定的示例资料，彩色长带记录该次执行节点。业务 Agent 可按权限查询工单、库存、交期及成本等实时数据，支持的写入有确认步骤。

## 可核对的关系

[业务]文档发布 —触发→ [业务]图谱同步
[业务]混合检索 —结合→ [证据]文档片段
[业务]混合检索 —结合→ [证据]图谱关系
