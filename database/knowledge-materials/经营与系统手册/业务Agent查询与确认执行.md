# 业务Agent查询与确认执行

适用范围　AI助手与知识库 · 业务 Agent

## 哪里查今天的工单、缺料和库存？

在业务 Agent 或生产决策中心的业务助手输入工单或产品编码、查询日期和需要的指标。按销售、生产、仓储等模块的实际权限查看业务结果。工单报表支持导出查询时的快照。

## 怎样让助手修改参考采购价或设备状态？

输入物料名称或编码、新价格，或设备编码和目标状态。先核对预览中的对象与变更，确认执行后查看回执。参考采购价保存为价格版本，采购入库行实际价格仍按单据维护。

## 为什么旧预览不能执行？

预览与当前用户及会话回合绑定，15 分钟有效。相关设备、工单、价格版本或结算金额变化时，重新生成预览，再核对并确认。
