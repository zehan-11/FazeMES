在 RAG 知识库选择对应库可以查看、下载原文。文档检索适合查操作步骤，图谱或混合检索适合核对实体关系。每个文件末尾列出建图关系，网页中的来源保留文档和版本。

个人教学手册在本机演示管理员名下。生产质量控制规则给测试生产主管、质检员、仓管员、设备员读取；经营与资料控制规则给测试生产主管和测试只读经理读取。规则管理员可维护。其他部署应按实际岗位设置授权。

Dify 项目手册问答另外索引了前三个目录的公共教学问答和原有点检样例。企业规则和现场样本通过 FazeMES 按库权限检索。后续在 FazeMES 替换文件时，发布流程负责更新 FazeMES 图谱。Dify 教学索引是单独的资料副本。

## 现场新增与修改
